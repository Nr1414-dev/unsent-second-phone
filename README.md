Entry for the make.fun bounty "Unsent: The Micro-Confession Sprint" — a two-part micro-confession, a To: line and the unsent message itself, judged head to head on how genuinely unsent it feels.

## Entry

`main.py` (Python 3) writes the confession to `/output/entry.txt` as UTF-8 text.

## Run locally

`python3 main.py` — writes `/output/entry.txt` (124 characters, two lines).
